# Changelog

## 0.5.0

- First standalone distribution, with its own Lua startup entry and mod manifest.
- Portable Windows bridge EXE with English/Chinese interface, automatic game-folder detection, DSX status, start/stop controls and single-instance protection. No separate Python installation required.
- Preserves the hardware-tested 0.4.1 effects: preloaded bow R2 resistance, stronger ReadyToFire stage, cancel/shot return to baseline, and stamina-driven L2/R2 for melee and empty hands.
- Ships no Cheat files, game files, personal paths, saves or test logs.
- Standalone automatic loading and feedback verified on Steam KCD1 1.9.7 / DSX 3.1.7 / USB DualSense on 2026-11-01.

## 0.4.1 (private prototype)

- Empty-hand fatigue no longer requires the weapon-drawn flag.
- No extra melee/unarmed resistance at 80%–100% stamina; ramps to 6/8 below 80%.
- User verified bow, sword, unarmed fatigue and recovery on KCD1 1.9.7 / DSX 3.1.7 over USB.
